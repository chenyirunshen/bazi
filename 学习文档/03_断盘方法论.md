# 八字断盘方法论

> 排盘是手艺，断盘是判断。这份讲**拿到一张盘后的思考顺序**。

---

## 一、六步断盘流程（固定套路，别跳步）

```
① 校时间 → 排出原局四柱（见 02 速查）
② 定日主强弱：得令 / 得地 / 得生 / 得势
③ 看调候：冬生要暖、夏生要润（优先级常高于扶抑）
④ 定格局：月令取格 → 辨顺用逆用 → 看成格破格
⑤ 取用神：扶抑 / 调候 / 通关 / 病药 / 从旺，五法择一
⑥ 走岁运：大运定十年基调，流年定应期
```

**顺序比口诀重要。** 前一步没稳，后一步的判断就是空中楼阁。

---

## 二、第一步：日主强弱（四看）

强弱不是数五行个数，是看**力量对比**：

| 要素 | 看什么 | 权重 |
|---|---|---|
| **得令** | 日主是否生于当令之月（如木生寅卯月）。**分量最重** | 最高 |
| **得地** | 地支有无本气根。根在**月支、日支**最有力；本气根 > 中气根 > 余气根 | 高 |
| **得生** | 有无印星（正偏印）生扶，印是否有根有透 | 中 |
| **得势** | 比劫是否成群结党 | 中 |

反向还要扣掉：**克（官杀）、泄（食伤）、耗（财星）** 的力量。

判读：
- **得令 + 通根** → 多半偏强
- **失令 + 无根** → 多半偏弱
- **不强不弱、五行流通** → 平和格，顺其流通方向看，别硬套扶抑

> ⚠️ 常见误判：**"八字里木多就是身强"** —— 错。没有根、不得令，四个木也可能虚浮无力。

---

## 三、第二步：调候（常被忽略，但《滴天髓》说它最急）

> 「天道有寒暖，发育万物，人道行之，不可过也。」

| 出生季节 | 命局偏性 | 优先需要的调候 |
|---|---|---|
| 三冬（亥子丑月） | 寒、湿 | **丙火、丁火**暖局解冻（无火暖，有才难展） |
| 三夏（巳午未月） | 燥、热 | **壬水、癸水**润泽滋培（无水润，性燥福薄） |
| 春、秋 | 相对中和 | 一般不需专门调候，回到生克格局 |

**调候用神失时，纵有富贵格局也多身心煎熬。** 这是《穷通宝鉴》的核心洞见。

---

## 四、第三步：定格局（《子平真诠》的路径）

### 取格规则（按优先级）

1. 月令**本气**透干于天干 → 以本气定格
2. 本气不透，月令**中气/余气**透干 → 以透出者定格
3. 月令所藏**皆不透** → 仍以月令本气定格（力量在支）
4. 月令为**比劫禄刃**（如甲生寅月）→ 不入八格，另寻财、官、食伤定格（"建禄用财官"）

### 八格与顺用逆用（这套是子平真诠最值钱的方法论）

**顺用四格** —— 吉神要"生之护之"，**忌克制**：

| 格 | 喜 | 忌 |
|---|---|---|
| 正官格 | 财生官、印护官 | 伤官克官（破格）、七杀混官（官杀混杂） |
| 正财格 | 食伤生财、官护财 | 比劫夺财 |
| 正印格 | 官杀生印、比劫护印 | 财星破印 |
| 食神格 | 比劫生食、财星泄食 | 偏印夺食（枭神夺食） |

**逆用四格** —— 凶神要"制之化之"，**忌生扶**：

| 格 | 喜 | 忌 |
|---|---|---|
| 七杀格 | 食伤制杀、印星化杀、合杀 | 财生杀而无制（杀重身轻） |
| 伤官格 | 印制伤（伤官配印）、财泄伤（伤官生财） | 官星（伤官见官，为祸百端） |
| 偏印格 | 财制枭、比劫泄枭 | 食神被夺 |
| 羊刃格 | 官杀制刃、食伤泄刃 | 无制则刚暴 |

### 格局成败三看

- **有情无情**：干支呼应、制化得当 = 有情；刑冲破害、互相悖逆 = 无情
- **有力无力**：用神通根月令、地支有强根 = 有力；虚浮无根 = 无力
- **清浊**：格局纯粹不杂 = 清；官杀混杂、财印交战 = 浊

## 五、第四步：取用神（五法）

| 法 | 何时用 | 取什么 |
|---|---|---|
| **扶抑** | 最基础。身强身弱明显 | 身强 → 官杀制、食伤泄、财星耗；身弱 → 印星生、比劫助 |
| **调候** | 寒暖燥湿偏差明显 | 冬生取火、夏生取水。**常优先于扶抑** |
| **通关** | 两行势均力敌相战 | 金木战 → 水通关；水火战 → 木通关；火金战 → 土通关；土木战 → 金通关；土水战 → 火通关 |
| **病药** | 某一行过旺或过弱成"病" | 《神峰通考》："有病方为贵，无伤不是奇"。能制病者为药 |
| **从旺** | 一气专旺或日主极弱无依 | 顺其气势，**不可逆** |

### 特殊格局

**专旺格**（顺其旺）：曲直（木）、炎上（火）、稼穑（土）、从革（金）、润下（水）
**从格**（弃命从势）：从财、从杀、从儿、从强
- 真从条件极严：日主**全局无根、无生扶、无破格字**
- 带微根或岁运引动，可能是"假从"

### 优先级（主流折中口径）

```
调候为急 → 通关次之 → 病药 → 扶抑
但以「月令格局」为总纲，用神服务于成格
```

各派优先级排序有争议，**不要求唯一答案，要求自洽**。

### ⚠️ 最大的民间误区

> **"八字缺什么就补什么" —— 这是最危险也最流行的伪命理。**

- 缺的不等于需要的。若缺的恰好是**忌神**，缺之大吉
- 日主强金生于秋月、火土重重，原局无木反而是清纯之象；强补木，木生火焚身，反招灾
- **用神是解药，不是填空**

## 六、第五步：找命局「最敏感的地方」

问三个问题：

1. **哪一类十神占的位置最重？**（哪个十神当令、透干、通根）
2. **有没有合局？有没有冲？**（合则牵绊，冲则动荡）
3. **哪一个字被孤立、被夹攻？**

答案就是这张盘**最容易被大运流年引动的位置**——也是断应期的着眼点。

---

## 七、第六步：走岁运

| 层级 | 管什么 | 时长 |
|---|---|---|
| **大运** | 十年一运，管**环境基调**（行的是什么运：财运？官运？印运？） | 十年一柱 |
| **流年** | 管**具体事件触发**（太岁） | 一年 |
| 小运/胎元/命宫 | 辅助参考，主流已少用 | — |

- 大运干支从**月柱**顺推或逆推
- 一般说法：**天干主前五年、地支主后五年**（也有"干支同参、干主外支主内"的说法，各家不同）
- **大运为地，流年为天**：大运决定你处在什么场，流年决定哪一年出事
- 应期判断：**冲、合、刑**引动的年份最容易应事；用神到位的年份应吉，忌神得势的年份应凶

## 八、常见误判清单

| 误判 | 正解 |
|---|---|
| 数五行个数定强弱 | 必须看得令、通根、透干、党众 |
| 身旺就好、身弱就差 | **中和为贵**。极旺极弱都可能入专旺/从格而成大格 |
| 轻易判从格 | 真从条件极严，带微根即破 |
| 用神只有一个且永远不变 | 用神随岁运有**动静之别**，大运变了喜忌可能转移 |
| 神煞当主菜 | 神煞是调料，正统子平以格局生克为主 |
| 一上来就断生死、断具体年份 | 命理给的是**倾向与概率**，不是确定性预言 |

## 九、验证记录模板（学成不自嗨的唯一办法）

光看理论会觉得自己全懂。建自己的命例库，先断后问：

| 命例 | 四柱 | 日主强弱 | 格局 | 用神 | 关键大运 | 我断的 | 实际应验 | 准否 |
|---|---|---|---|---|---|---|---|---|
| 张三 19xx-xx-xx | 甲戌 己巳 甲寅 辛未 | 偏弱 | 正官格 | 印（水） | 21–30 壬申 | 事业有贵人提携 | 28 岁进体制 | ✓ |

**积累 20 个真实命例的验证记录，比背 100 条口诀有用。**

---

## 十、一句话总纲

> 旺衰看平衡 · 格局看上限 · 调候看冷暖 · 盲派看人事 · 岁运看时机。

成熟的做法不是选边站，而是**四层叠加**：
层次高低用格局，气场利弊用旺衰，顺逆舒适用调候，具体人事用象法/盲派。
