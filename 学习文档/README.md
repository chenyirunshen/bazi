## 三句话速记

1. **八字看的是气**：八个字之间的生克制化，以及这条链转不转得通。
2. **月令是提纲**：判断强弱、定格局、取用神，第一眼都看月支。
3. **用神是解药不是填空**：缺什么补什么是最危险的伪命理。

## 与紫微系统的关键差异

| | 紫微斗数 | 八字 |
|---|---|---|
| 年柱分界 | 农历**正月初一** | **立春**交节时刻 |
| 排盘核心 | 命宫、五行局、紫微定位 | 节气交节（**精确到分钟**）、真太阳时、早晚子时 |

> ⚠️ 八字对时间精度要求更高：节气时刻差几分钟，月柱就完全不同。
> 这也是自己搭八字排盘工具的最大技术门槛（需要 1900–2100 年**分钟级**节气数据）。
