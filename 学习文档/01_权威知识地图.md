## 一、先搞清八字到底是什么

八字不是"算命"，是**一套符号推演系统**：把出生时刻换算成干支历的八个字，再用阴阳五行的生克制化规则，推演这八个字之间的力量关系，最后翻译成人事语言。

它和紫微斗数的关系（你已经在学斗数，这个对照很重要）：

| | 紫微斗数 | 八字（子平） |
|---|---|---|
| 核心符号 | 星曜（14 主星 + 辅煞） | 干支（8 字）＋ 十神 |
| 推演方式 | 星落宫、四化 | 五行生克、刑冲合会 |
| 长项 | 性格气质、宫位人事、象 | 层次高低、运势曲线、五行失衡 |
| 时间粒度 | 大限十年、流年 | 大运十年、流年 |
| **年柱分界** | **农历正月初一** | **立春交节时刻** |

⚠️ 最后一行是两套系统最容易串线的地方。你用斗数系统排八字，年柱会错。

## 二、历史脉络（知道来路，才知道每本书在解决什么问题）

| 时期 | 关键人物/事件 | 范式 |
|---|---|---|
| 唐 | 李虚中 | **古法（禄命法）**：以年柱为主，三柱六字，重纳音、神煞 |
| 北宋 | 徐子平（托名） | **今法（子平法）**：改以**日干**为中心，用正五行论旺衰 —— 八字这一脉由此而来 |
| 宋 | 徐大升编《渊海子平》 | 子平法第一次系统化，术语总纲 |
| 明 | 万民英《三命通会》 | 集大成，唯一入《四库全书》的命理著作，60 万字、1200+ 命例 |
| 明 | 张楠《神峰通考》 | 提出「病药说」：有病方为贵，无伤不是奇 |
| 清 | 沈孝瞻《子平真诠》 | 格局理论巅峰，48 篇专求月令 |
| 清 | 任铁樵注《滴天髓阐微》 | 旺衰派圣典，512 个实战案例 |
| 民国 | 袁树珊、韦千里、徐乐吾 | "民国三大家"，命理从术数转向文人学问 |
| 当代 | 梁湘润（台）、钟义明（台）、段建业（盲派）、陆致极（学术） | 分化为格局/旺衰/盲派/量化研究四条路 |

> 学术上最扎实的一部源流考据：**陆致极《中国命理学史论》**（上海人民出版社，2008）。
> 他梳理出「纳音古法 → 明代中叶过渡形态 → 正五行子平今法」的完整链条，填补了这块空白。

## 三、核心古籍：五本，各读什么

**不要一上来啃《滴天髓》——那是公认的新手劝退书。**

| 顺序 | 书 | 定位 | 读什么 |
|---|---|---|---|
| 1 | **《渊海子平》**（宋·徐大升） | 术语总纲 | 天干地支体象、十神、基本格局、排盘术语。建立词汇表的第一站 |
| 2 | **《子平真诠》**（清·沈孝瞻） | 格局教科书 | 月令定格、顺用逆用、成格破格、相神护格。**命理界的《几何原本》** |
| 3 | **《三命通会》**（明·万民英） | 百科辞典 | 有基础后**当工具书翻**，查神煞、查杂格、查古人断例。不要通读 |
| 4 | **《穷通宝鉴》**（明·佚名，清·余春台整理） | 调候专书 | 十天干 × 十二月的寒暖燥湿喜忌。「金不离丁，火不离甲」这类口诀出自此 |
| 5 | **《滴天髓》**（旧题宋·京图，清·任铁樵《阐微》） | 高阶心法 | 旺衰真机、清浊、气势流通。**最后读**，读完才算从"算八字"到"懂命理" |

外加两本实战补充：
- **《千里命稿》**（民国·韦千里）——**最适合现代人的第一本**，讲义体，100+ 名例，手把手教你为什么这么断。
- **《神峰通考》**（明·张楠）——病药说，断层次直给。

## 四、现代书单（按你的阶段选，不要全买）

### 入门：先建立结构感

| 书 | 作者 | 为什么 |
|---|---|---|
| 《千里命稿》 | 韦千里 | 案例具体，讲「为什么这样断」而不只给结论 |
| 《八字入门》《命理精论》 | 胡一鸣（台） | 主张平理正理，反对神煞玄学化，专治"见神煞就断吉凶" |
| 《四柱预测学》 | 邵伟华 | 大陆命理启蒙之作，排盘/大运/流年标准化讲得极细。技法有争议，当工具书用 |

### 进阶：把流派打通

| 书 | 作者 | 体系 |
|---|---|---|
| 《子平母法总括》《八字提要》《流年法典》《金不换大运详解》 | **梁湘润**（台） | 台湾命理界泰斗。把枯涩古法转成可操作的**程式**，禄命法与子平法结合，重神煞纳音的辅助作用 |
| 《命理用神精华》《命理脑筋急转弯》《命理乾坤》《现代破译滴天髓》 | **钟义明**（台） | 用神专题最系统，适合啃透"用神到底怎么取" |
| 《命理点睛》 | 吴怀云（台） | 薄，但极通透 |
| 《八字泄天机》 | 司莹居士（台） | 实战向 |

### 专项：按需读

| 方向 | 书 |
|---|---|
| 格局法正本清源 | 黄大陆《子平真诠讲义》（纠正民国以来"轻格局重用神"的倾向） |
| 盲派（断具体人事） | 段建业《盲派命理》《命理珍宝》《命理瑰宝》；邢秀芬《盲派八字讲义》 |
| 象法（怎么开口断事） | 曲炜《四柱信息取象》《四柱详真》；李顺祥《四柱玄机》 |
| 新派（**了解即可，别当主菜**） | 李涵辰《八字预测真踪》——上手快，但废神煞、废刑冲合害，简化了太多 |

### 学术与批判视角（这条最适合你）

| 书 | 作者 | 价值 |
|---|---|---|
| **《中国命理学史论》** | 陆致极 | 首部系统命理史，把命理学从俗文化引入学术殿堂 |
| **《八字与中国智慧》** | 陆致极 | 提出八字有**两大结构网络**：日主网络 + 格局网络。这个框架极清晰 |
| 《又一种"基因"的探索》《解读时空基因密码》 | 陆致极 | 计算语言学背景，用逻辑回归/聚类做命理量化研究，尝试可检验的数据模型 |
| 《中国人的命理信仰》 | 董向慧 | 社会学视角，看命理为什么在现代社会依然有生命力 |
| 《中国古代算命术》 | 洪丕谟、姜玉珍 | 通俗可靠的通识读本 |

> 陆致极是这一块唯一有**计算语言学博士**背景的人（复旦中文硕士 → 伊利诺大学语言学博士）。
> 他的态度值得抄：**命理学揭示的是统计学意义上的相关性，统计相关性本身并不保证因果联系。**

## 五、推荐阅读顺序（三阶段）

```
阶段一（打底 1–2 个月）
  韦千里《千里命稿》+ 胡一鸣《八字入门》
  同时：每天手排自己/家人的盘，把四柱、十神、大运排顺
  ↓
阶段二（立骨架 3–6 个月）
  《渊海子平》选读（补术语）→《子平真诠》（练格局取用神）
  同时：每读一条断语，倒回去问「它说谁？条件是什么？换月令还成立吗？」
  ↓
阶段三（开眼界 6 个月+）
  《滴天髓阐微》（练旺衰与流通）→《穷通宝鉴》（补调候）
  →《三命通会》当辞典翻 → 选一个专项（盲派 或 象法）
  → 陆致极，回头看这套东西在学术上到底是什么
```

**一条硬规矩：每读一层，必须配命例。**
只看理论会觉得自己全懂，拿一张盘出来才知道哪一步是虚的。

## 六、六个必避的坑

| 坑 | 真相 |
|---|---|
| ❌ "八字缺什么就补什么" | **最危险的伪命理**。若缺的恰好是忌神，缺之大吉。补了反招祸。用神不是"填空" |
| ❌ 直接从《滴天髓》入门 | 难不在字多，在字少。一句"配合干支仔细详"，落到盘上要看强弱、进退、位置、全局关系 |
| ❌ 混派 | 一本里的"用神"还没吃透，就拿另一派的定义去改它。名词一样，意思早乱了 |
| ❌ 把软件的用神当圣旨 | 10 秒出一盘的免费工具，用神算法大多有争议。**先懂原理，才能判断软件给的合理不合理** |
| ❌ 死记断语 | 每条断语都要回到**成立的结构条件**。见"某某格主大富"就往上套，必翻车 |
| ❌ 只看古籍不看现代 | 古籍形成于宗法社会，六亲、妻妾、官爵的现代对应要打折扣重译 |

## 七、工具与数据源（你要是自己写代码，看这里）

| 用途 | 选择 | 说明 |
|---|---|---|
| 历法/干支/节气/八字库 | **lunar-python（6tail）** | 你紫微系统已在用它的移植版。支持八字、五行、十神、纳音、大运。1901–2099 |
| 另一套无依赖农历 | **cnlunar** | 不用寿星通式，用**香港天文台数据**，节气准；以《钦定协纪辨方书》为核心；支持八字月柱两种算法 |
| 节气精度 | 寿星万年历 / 香港天文台 | **八字排盘最大的技术坑就是节气时刻**。必须精确到分钟，不能按"日期"近似 |
| 前端八字排盘参考 | 8Char-H5（UniApp） | 完成度高，可参考其交互 |

⚠️ 技术侧三个必须处理的点（详见 `02_排盘技术速查.md`）：
1. **真太阳时**（经度差 + 均时差，全年最大 ±16 分钟）
2. **夏令时**（中国 1986–1991 实行过，这六年出生的人必须回拨）
3. **早晚子时**（23:00–01:00 跨日，日柱怎么定，流派有分歧）

## 八、边界声明（请一直带着）

- 命理属**传统文化与符号推演**范畴，不是自然科学。
- 陆致极的定位最中肯：**统计学意义上的相关性描写，不保证因果联系。**
- 它的价值在于提供一套**自我觉察与风险认知的语言**，不在于给出确定性预言。
- 真正决定走向的是：认知 + 选择 + 环境 + 行动。命盘是地图，不是轨道。
