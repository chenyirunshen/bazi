## 序：这份要纠正的最大一个错误

几乎所有入门教程都会写一句：

> ❌ **"调候就是冬天补火、夏天补水。"**

这句话**在方向上是通俗的，在方法上是错的**。它把一个 120 格的精密体系，压缩成了 2 格。

举三个反例，你立刻能看出它错在哪：

| 日主 | 月份 | 季节 | "冬火夏水"会说 | 《穷通宝鉴》实际要求 |
|---|---|---|---|---|
| 甲木 | 酉月 | 秋 | 不管（不冷不热） | **庚金为主，丙丁调候**——甲木秋天要被修剪才成材 |
| 丙火 | 午月 | 盛夏 | 补水 | **壬水**（不是随便的水，是要江湖之水映太阳，癸水雨露不行） |
| 丁火 | 子月 | 严冬 | 补火 | **甲木**——丁火是灯烛，添油（甲）比加火有用，**且必须兼庚劈甲** |
| 庚金 | 午月 | 盛夏 | 补水 | **壬水**（顺带泄秀），但庚金**四季都要丁火来炼**，只有丁火才是庚金的成型条件 |

看明白了吗？**调候不是按季节抄答案，是按"这个天干在这个月令下，最需要什么才能成器"来查表。** 十天干 × 十二月令 = 120 种组合，各有各的答案。

## 一、《穷通宝鉴》调候：十干逐月体系

### 1.1 这本书在讲什么

《穷通宝鉴》（又名《拦江网》，旧题"江湖金不换"）是**唯一一本以"调候"为唯一主线**的古籍。它的底层逻辑不是生克，是**物理**：

> 万物生长靠气候。日主就是一粒种子，月令就是它落地的那个月的天气。
> 天气太冷要暖，太热要凉，太燥要润，太湿要干。
> **气候调顺了，命局才有"活气"；调不顺，格局再正也发不出来。**

所以它关心的是**寒、暖、燥、湿**四个字，而不是"我克谁、谁克我"。

### 1.2 十干性情：调候表的"为什么"

背表之前先记住十干各自是什么东西，表就不用背了——**你能自己推出来**：

| 天干 | 象 | 它怕什么 | 它要什么（核心） |
|---|---|---|---|
| **甲** | 参天大树 | 金重砍断、水多漂根 | **丙**（阳光暖）· **庚**（斧斤裁成）· **癸**（雨露润） |
| **乙** | 花草藤萝 | 强金、寒冻 | **丙**为主，**癸**略取——藤萝要暖，水多了烂根 |
| **丙** | 太阳 | 晦火无光 | **壬**（江湖映日）——"丙火太阳，壬水为映，方成既济" |
| **丁** | 灯烛星火 | 无油自灭 | **甲**（油）· **庚**（劈甲引丁）——没甲就点不着，没庚劈不开甲 |
| **戊** | 城墙堤岸 | 湿重崩塌 | **甲**（疏土）· **丙**（暖）· **癸**（润）——土要松、要暖、要润 |
| **己** | 田园湿土 | 寒凝不生 | **丙**（暖）· **癸**（润）——田园土靠太阳和水才长庄稼 |
| **庚** | 刀剑矿石 | 不炼不成器 | **丁**（炉火锻造）四季皆需——"庚金带煞，刚健为最，得火而锐" |
| **辛** | 珠玉首饰 | 土埋、污浊 | **壬**（水洗淘）——"辛金软弱，温润而清，乐水之盈"；冬月兼**丙**暖 |
| **壬** | 江海奔流 | 无堤泛滥 | **戊**（堤坝）· **丙**（暖）· **庚辛**（源头） |
| **癸** | 雨露润泽 | 无源干涸、冻结 | **辛**（发源）· **丙**（温暖）——雨露要有源头、不能冻 |

> 记住"甲要庚裁、丙要壬映、丁要甲庚、庚要丁炼、辛要壬淘"这五条，你就抓住了这张表的骨架。

### 1.4 怎么用：三条实操规则

**规则一：查表拿到的只是一个"字"，不是结论。**
拿到第一调候（比如丁火子月的"甲"）之后，要问三件事：
1. 局里**有没有**这个字？（天干有没有透？地支藏干里有没有？——App 会自动查，含藏干）
2. 有的话，**有没有根、有没有被破**？甲木被庚克、被己合，等于没有。
3. 没有的话，**大运补不补得上**？调候在原局没有，就看大运什么时候走到——**那一步运，往往就是人生的转折点**。

**规则二：调候用神与扶抑用神冲突时，调候优先。**
这是《穷通宝鉴》一派的硬规矩。理由很朴素：**冻死的人不需要补营养，先要火。**
身弱又寒的八字，先暖起来，再谈扶抑。所以 App 里把"调候"的优先级设为最高（冬夏月令 urgent = 1，其余月份 = 2）。

**规则三：调候是"加分项"，不是"格局替代品"。**
《穷通宝鉴》自己没说调候能替代格局。完整的顺序是：

> **格局定贵贱 → 调候定舒泰 → 扶抑定安危 → 通关/病药定细节**

一个八字调候很好但格局破了：一生过得舒服，但上不去。
反过来格局成了但调候差：能上去，但过得拧巴、身体与心境都不舒展。

### 1.5 校勘说明（重要）

市面流传的"调候用神简表"**有多处讹误**，我核对时重点处理了这几处，本表取的是原文第一用神：

- **甲木秋冬**：不少简表写作"专用庚金"了事，漏了**丁火**。原文是"用庚、丁、丙"，冬月甲木**丁为必须**（子月：丁先庚、丙后）。
- **丙火秋冬**：简表常误作"用壬"一以贯之，但**戌亥两月原文先取甲**（丙火入墓绝之地，先要甲木生扶，再论壬水），本表按原文订正为甲。
- **丁火卯月**：简表多作甲，原文实际是**庚、乙并用，无乙用甲**——卯月乙木当令，丁火附乙而明。
- **庚金四季**：简表常只写"丁火"，但**寅月先取戊、戌月先取甲**——寅月庚金绝地要戊土生，戌月土厚要先甲疏。

> ⚠️ 不同流派（尤其是港台现代派与内地古籍派）在个别月令上仍有分歧。
> 本表的处理原则：**以《穷通宝鉴》原文的第一用神为准**，争议处保留原文的"次用"说明，不替你选边。

## 二、《子平真诠》格局：成格条件与相神

### 2.1 八格成格条件

很多人会定格局名（"这是正官格"），但**定名 ≠ 成格**。下面这张表才是关键——**每一格都有它"成立"的具体条件，不满足就是破格**：

| 格局 | 成格条件（《子平真诠》原文意旨） |
|---|---|
| **正官格** | 官逢财印，又无刑冲破害 |
| **财格** | 财旺生官；或财逢食生而身强带比；或财格透印而位置妥适，两不相克 |
| **印格** | 印轻逢煞；或官印双全；或身印两旺而用食伤泄气；或印多逢财而财透根轻 |
| **食神格** | 食神生财；或食带煞而无财，弃食就煞而透印 |
| **七杀格** | 身强七煞逢制伏 |
| **伤官格** | 伤官生财；或伤官佩印而伤官旺、印有根；或伤官旺、身主弱而透煞印；或伤官带煞而无财 |
| **阳刃格** | 透官煞而露财印，不见伤官 |
| **建禄月劫格** | 透官而逢财印；透财而逢食伤；透煞而遇制伏 |

> 注意最后两格：**建禄 / 月刃**是"月令本气为比劫"时的特殊处理，不走八格逻辑，别被中气/余气覆盖掉。

### 2.2 吉神顺用、凶神逆用（原文）

这是《子平真诠》最有分量的一句话，值得背下来：

> 「是以**善而顺用之**，则财喜食神以相生，生官以护财；官喜透财以相生，生印以护官；印喜官煞以相生，劫才以护印；食喜身旺以相生，生财以护食。
>
> **不善而逆用之**，则七煞喜食神以制伏，忌财印以资扶；伤官喜佩印以制伏，生财以化伤；阳刃喜官煞以制伏，忌官煞之俱无；月劫喜透官以制伏，利用财而透食以化劫。」

拆成人话：

| 类型 | 十神 | 怎么对待 | 逻辑 |
|---|---|---|---|
| **吉神（顺用）** | 财、官、印、食 | **生之、护之** | 好东西要养着、帮着 |
| **凶神（逆用）** | 杀、伤、枭、刃 | **制之、化之** | 坏东西要管着、转化它 |

> 这条是判断**用神取什么**的 shortcut：格神是吉神，就找能生它护它的字；格神是凶神，就找能制它化它的字。

### 2.3 相神：比格神还重要

《子平真诠》里有个容易被忽略但极关键的概念——**相神**。

> **相神 = 保护格神的那个字。**
> **相神受伤，比格神受伤危害还大。**

举例：
- **正官格**，官星怕伤官来克。谁能制伤官？**印**。所以官格的相神是印。
  → 如果印被财星破掉（财克印），官格就立不住了。这就是"**相神受伤，格破**"。
- **七杀格**，杀要食神来制。食神就是相神。
  → 如果食神被枭神夺走（枭神夺食），七杀无制，凶。

**实务用法**：定格局之后，不要只看格神在不在，**先找相神在不在、有没有被伤**。这一步很多人跳过了，结果判断全错。

## 三、格局法 vs 扶抑法：两套体系别硬套

这是现代八字圈最大的混乱来源——**两套东西被混着讲**。

| | **格局法**（《子平真诠》体系） | **扶抑法**（旺衰平衡体系） |
|---|---|---|
| **中心** | 月令**格神** | **日主** |
| **问的问题** | 这个结构成不成立？ | 这个人扛不扛得住？ |
| **判断对象** | 格局成破 | 身强身弱 |
| **方法** | 吉神顺用、凶神逆用 | 身旺则泄克耗，身弱则生帮 |
| **擅长** | 判**层次高低**（贵贱） | 判**承载力、健康、抗压** |
| **局限** | 不关心你舒不舒服 | 不关心你能不能上去 |

### 为什么不能混

同一个八字，格局法可能判"**成格，有贵**"，扶抑法可能判"**身弱，扛不住**"。
**这两句话并不矛盾**——它们在说两件事：

> 格局成了，说明你有上去的**通道**；
> 身弱，说明你上去的**过程很累**，且承载力有限。

真实的人生图像是：**能上去，但很辛苦，且要挑对运。** 这才是完整答案。

### 实务上怎么用

```
格局  → 判层次（能到什么位置）
扶抑  → 判安危（什么时候会撑不住）
调候  → 判舒泰（身心状态、人生体感）
三者合看，才是完整的八字解读。
```

一句话记住：**格局定贵贱，扶抑定安危。**

## 四、六亲：十神告诉你"是谁"

十神除了讲生克，还直接对应**人**。这是八字最实用的一块。

| 十神 | 男命 | 女命 | 备注 |
|---|---|---|---|
| **正印** | 母亲、长辈、师长、学历文凭、庇护 | 同 | 无正印则看偏印 |
| **偏印** | 继母、庶母、偏门学问与技艺 | 同 | 正统以外的一切"生我"之力 |
| **正财** | **妻子**、固定资产、稳定收入 | 钱财、务实经营 | 男命正财为正妻 |
| **偏财** | **父亲**、投资经营、人脉资源、意外之财 | 同 | 偏财为父，古今通用；无偏财看正财 |
| **正官** | 女儿、职位、规则、名誉 | **丈夫**、职位、规则、名誉 | 女命正官为正夫，无正官看七杀 |
| **七杀** | **儿子**、压力、竞争、魄力 | 偏夫、情人、压力、竞争 | 男命七杀为儿子 |
| **食神** | 才华表达、口福、技艺 | **女儿**、福寿、才艺、温和 | 女命食神为女儿 |
| **伤官** | 才华、反叛、创意、技艺 | **儿子**、才华、傲气 | 女命伤官为儿子 |
| **比肩** | 兄弟、同辈、朋友、竞争者 | 姐妹、同辈、朋友、竞争者 | |
| **劫财** | 姐妹、合作伙伴、分利者 | 兄弟、合作伙伴、分利者 | |

> ⚠️ **注意性别转换**：同一十神，男女命指向不同人。这是初学者最容易搞错的地方。
> 尤其"女命正官为夫、男命正财为妻"这两条，是断婚姻的入口。

### 六亲的"有没有"与"好不好"

看六亲要分两步，别一步跳到吉凶：

1. **有没有** —— 该十神在局中出现吗？不出现不代表"没有这个人"，代表**缘分淡 / 关系形态特殊**。
2. **好不好** —— 出现之后，看它：
   - 是否**得位**（坐的地支对不对）
   - 是否**被克破**（比如财星被比劫夺、官星被伤官克）
   - 与日主的**远近**（年月为早/远，日时为近/亲）

## 五、宫位：十神告诉你"在哪儿"

光有六亲（谁）不够，还要知道**这件事发生在哪个位置、什么阶段**。这就是宫位。

| 四柱 | 宫位名 | 管什么 | 大致年龄段 |
|---|---|---|---|
| **年柱** | 祖上宫 | 祖辈、根基、童年环境、与父母家族的缘分 | 1–16 岁 |
| **月柱** | 父母兄弟宫 | 父母、兄弟姐妹、青年环境、事业起步的平台 | 17–32 岁 |
| **日柱** | 夫妻宫 | 自己与配偶。**日干是我，日支是配偶的位置** | 33–48 岁 |
| **时柱** | 子女宫 | 子女、晚辈、晚年归宿、成果与输出 | 49 岁以后 |

### 三段式判断法：十神 + 宫位 + 运程

把三者拼起来，才是一个完整的判断：

> **十神 = 是谁**（what / who）
> **宫位 = 在哪儿**（where）
> **大运流年 = 什么时候**（when）

**例子**："父亲身体出问题"这件事
- 十神：偏财（= 父亲）
- 宫位：看年月柱（父母宫、祖上宫）
- 运程：哪一步大运**冲克**了那个偏财，或流年**并临**其上

三步都对上，才敢说；只对一个，只能说"留意"。

> ⚠️ **年龄段是粗略参考，不能当钟表用**。它表示的是"这一段人生的主要议题落在哪个领域"，不是精确的应期。

## 六、现代学术视角：这套东西到底靠不靠谱

学命理，**必须同时知道它被批评什么**。否则你学的是信仰，不是知识。

### 6.1 陆致极：把命理当"假说"来研究的人

陆致极是当代把八字研究做得最系统的学者之一（公开资料：复旦大学中文系硕士，后获美国伊利诺大学语言学博士，长期从事汉语研究与命理史研究）。代表作《中国命理学史论》《命运的求索》《八字命理基础教程/进阶教程》。

他做了两件有意思的事：

**① 梳理命理史**——把从唐代李虚中（三柱）、宋代徐子平（加时柱、立格局）到明清《子平真诠》《滴天髓》《穷通宝鉴》的演变脉络整理清楚，指出**命理本身是一部"解释模型的演化史"**，而不是一部天启真理史。

**② 提出"时空基因"假说**——他尝试用一种现代语言重新表述命理：
> 出生时刻对应的干支五行结构，类似于一种**"时空编码"**，可能对应个体禀赋的某种倾向性分布。

注意他用的词是**"假说"**。这一点很重要——一个认真做研究的人，会自己标明这是假说，而不是宣称"科学已证实"。

### 6.2 四条站不住的地方（学界常见的批评）

这四条是严肃批评，不是外行的嘲讽。你必须能逐条说出来：

| # | 批评 | 具体是什么 |
|---|---|---|
| 1 | **不可证伪** | 按波普尔标准，一个理论要能说出"什么情况下我承认自己错了"。命理的很多表述具有高度弹性（"有这个象但被化解了"），难以给出明确的反例条件 |
| 2 | **不可重复** | 同一个八字，不同流派、不同师傅给出的结论常常不一致；同一师傅在不同时间也可能改口。缺乏可重复的判定程序 |
| 3 | **缺乏机制** | 从"出生时刻的天干地支"到"具体人生事件"，**中间的因果链条是空白的**。没有任何已知的物理、生物或社会机制可以解释这条链 |
| 4 | **无显著因果** | 已有的统计尝试（包括陆致极自己做的）**未能得出稳健、可复制的显著相关性**。样本、控制变量、多重比较等问题都很难处理 |

### 6.3 巴纳姆效应：为什么你会觉得"好准"

这是最致命的一条，而且**你自己会中招**。

1948 年，心理学家 Bertram Forer 给学生做了一份"个性测验"，然后给每个人发了一份"专属于你的性格分析"，让学生打分准不准——平均 4.26 / 5 分，几乎人人都说准。
**实际上所有人拿到的是同一段话**，内容是这种风格的：

> "你需要别人喜欢和欣赏你，但你往往对自己相当挑剔。"
> "你有很多未被开发的潜能，还没有转化为你的优势。"
> "你外表自信，内心时常有些不安。"

这就是**巴纳姆效应（Barnum Effect / Forer Effect）**：人会把**模糊、普适、正面为主**的描述，认同为"精准地说中了我"。

命理话术天然具备巴纳姆效应的全部要素：
- **模糊**："中年有一劫"——谁的中年没有低谷？
- **双向**："感情上易生波折"——波折可大可小，事后总能找到对应
- **正面偏差**：好听的话更容易被记住，不准的话被自动遗忘（**确认偏误**）

### 6.4 那还值得学吗

值得，但**要换一个定位**：

| ❌ 不要当成 | ✅ 可以当成 |
|---|---|
| 预测未来的工具 | 一套**结构化的自我描述语言** |
| 客观事实 | 一种**传统文化的符号系统** |
| 决策依据 | 一个**反思与提问的框架** |
| 科学理论 | 一门**有 1200 年演化史的解释学** |

**我的建议定位**：

> 把八字当成**一套迫使你结构化思考"我是谁、我在什么位置、什么时候该进该退"的语言**。
> 它的价值不在于"算得准"，而在于**它逼你把人生拆成格局（能力结构）、调候（身心状态）、六亲（关系）、运程（节奏）四个维度去审视**——这个拆解动作本身就有价值。

一句必须记住的话：

> **用它来提问，不要用它来下结论。**

## 七、把四套拼起来：完整判断流程

```
① 排盘核对（历法层）
   立春换年 · 节换月 · 真太阳时 · 夏令时 · 早晚子时口径
   ↓ 这一步错，后面全错

② 看日主强弱（扶抑层）
   得令 · 得地 · 得生 · 得势 · 克泄耗
   → 判：身强 / 偏强 / 中和 / 偏弱 / 身弱
   ↓

③ 查调候（气候层）★ 新增的精度
   十干 × 月令查表 → 第一用神在不在（含藏干）？有没有根？有没有被破？
   → 冬夏月令调候最急，优先级最高
   ↓

④ 定格局（结构层）
   月令本气 → 八格 / 建禄月刃 / 不入格
   → 查成格条件 → 找相神 → 相神有没有受伤
   ↓

⑤ 取用神
   调候 → 通关 → 扶抑（顺序）
   排出喜神 / 忌神
   ↓

⑥ 断六亲宫位（人事层）★ 新增的精度
   十神 = 谁 · 宫位 = 在哪儿 · 大运流年 = 什么时候
   ↓

⑦ 排岁运
   起运岁数 → 大运顺逆 → 每十年一运 → 叠加流年
   先看大运背景，再看流年具体事件
```

## 八、常见误读纠偏表

| 常见说法 | 问题在哪 | 正确说法 |
|---|---|---|
| "调候就是冬补火夏补水" | 把 120 格压成 2 格 | 十干 × 十二月令各有答案，查表 |
| "缺什么补什么" | 最危险的伪命理 | 用神是**解药**，不是**填空**。缺的可能是病，补它反而坏事 |
| "身强就好，身弱就差" | 混淆了格局法与扶抑法 | 格局成，身弱也可有贵；格局破，身强也多波折 |
| "定出格局名就完了" | 定名 ≠ 成格 | 还要查成格条件 + 相神有无受伤 |
| "正官格就一定是当官的" | 把十神当职业 | 十神是**关系与结构**，不是职业标签 |
| "这个八字很准" | 可能是巴纳姆效应 | 要求可重复、要求对照组，再谈准不准 |
| "八字能算出具体事件" | 超出模型能力 | 八字给的是**倾向与节奏**，不是事件清单 |
